Конвертация времени UTC ↔ локальное

Правильная конвертация datetime-local → UTC → отображение в локальной таймзоне. Ключевые моменты:



Хранение — toISOString() (UTC).



Отображение — toLocaleString('ru-RU').



datetime-local интерпретируется как локальное, поэтому new Date(localValue) даёт UTC автоматически.



Проверка пересечений с полуоткрытыми интервалами

Условие aStart < bEnd \&\& aEnd > bStart работает корректно только для полуоткрытых интервалов \[start, end). Если ошибиться и использовать <=, то смежные брони (когда end одной равен start другой) будут считаться конфликтом.



2\. Допущения (что требует доработки)

2.1. Данные не сохраняются между перезагрузками

Сейчас брони живут в in-memory массиве внутри MSW. При перезагрузке страницы изменения сбрасываются.



Что нужно: перейти на IndexedDB (рекомендация ТЗ) или на реальный backend.



2.2. Нет авторизации

Есть только заготовка (AuthContext). Нет экрана логина, нет ролей, нет разграничения прав.



Что нужно: подключить backend /api/auth/login, хранить JWT, добавить interceptor в axios.



2.3. Нет drag-and-drop

ТЗ рекомендует drag-and-drop для переноса броней на таймлайне. Это не реализовано.



Что нужно: библиотека типа dnd-kit или react-dnd.



2.4. Нет расписания в виде календаря

Только список броней. Нет визуализации по дням/неделям.



Что нужно: компонент Calendar из MUI или сторонней библиотеки.



2.5. Импорт не реализует политику Replace/Merge

Сейчас импорт валидирует файл и показывает отчёт, но не применяет изменения к данным.



Что нужно: при переходе на IndexedDB/backend — реализовать обе политики.
