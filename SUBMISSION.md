\## Краткое описание



\*\*Room\&Assets\*\* — SPA для управления каталогом ресурсов (аудитории + инвентарь) и бронированиями.



Приложение работает \*\*без сервера\*\*: все данные локальные, все HTTP-запросы перехватываются \*\*MSW\*\* (Mock Service Worker). Backend-заготовка (Fastify + Prisma + PostgreSQL) лежит в папке `backend/`, но не подключена — для лабы №1 не требуется.



\## Что реализовано



\- Каталог аудиторий с поиском и фильтром по вместимости.

\- Каталог инвентаря с поиском по названию и коду.

\- Создание / редактирование / удаление броней.

\- Проверка пересечений интервалов (полуоткрытые `\[start, end)`).

\- Экспорт / импорт всего состояния в JSON с валидацией.

\- Хранение времени в UTC (RFC 3339), отображение в локальной таймзоне.

\## Моки (MSW)



Все эндпоинты:

\- `GET /api/rooms`

\- `GET /api/assets`

\- `GET /api/bookings`

\- `POST /api/bookings` (с проверкой пересечений)

\- `PATCH /api/bookings/:id`

\- `DELETE /api/bookings/:id`



Контракты описаны в `docs/DATA.md`. При переходе на реальный backend \*\*код компонентов не меняется\*\* — только URL в `http.ts`.
