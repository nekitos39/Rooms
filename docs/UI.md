\# UI — Описание экранов



\## Общий каркас



\- \*\*Шапка\*\* (Header) — навигация: Каталог, Управление бронированием, Импорт/Экспорт. Справа — иконка уведомлений и аватар.

\- \*\*Контент\*\* — меняется в зависимости от вкладки.



\## Экран 1. Каталог



\### 1.1. Таб «Аудитории»



\- Поле \*\*поиска\*\* по названию или номеру.

\- Поле \*\*«Мин. вместимость»\*\* (число).

\- Таблица:

&#x20; - Номер

&#x20; - Название

&#x20; - Вместимость

&#x20; - Оборудование (Chips)

&#x20; - Статус (Chip: Доступна / Забронирована / На обслуживании)

&#x20; - Действия



\### 1.2. Таб «Инвентарь»



\- Поле \*\*поиска\*\* по названию или инвентарному номеру.

\- Таблица:

&#x20; - Инв. номер

&#x20; - Название

&#x20; - Статус (Chip: Доступен / Используется / На обслуживании / Списан)



\## Экран 2. Управление бронированием



\### 2.1. Форма создания/редактирования



\- Выпадающий список \*\*«Аудитория»\*\* (обязательно).

\- Поле \*\*«Название брони»\*\* (обязательно).

\- Поле \*\*«Время начала»\*\* (datetime-local, обязательно).

\- Поле \*\*«Время окончания»\*\* (datetime-local, обязательно).

\- Кнопка \*\*«Забронировать»\*\* / \*\*«Сохранить изменения»\*\*.

\- Кнопка \*\*«Отменить»\*\* (в режиме редактирования).



\### 2.2. Список броней



\- Таблица: Название, Аудитория, Время начала, Время окончания, Действия.



\## Экран 3. Импорт/Экспорт



\### 3.1. Блок «Экспорт»



\- Описание.

\- Схема: v1.0 · Формат: RFC 3339 / UTC.

\- Кнопка \*\*«Скачать JSON»\*\*.



\### 3.2. Блок «Импорт»



\- Описание.

\- Кнопка \*\*«Выбрать файл»\*\*.

\- После выбора — валидация: схема, ссылочная целостность, формат времени, пересечения.

\- Alert с результатом (success / error).



\## Принципы



\- \*\*Локальное время в UI, UTC в данных.\*\*

\- \*\*Валидация на клиенте.\*\*

\- \*\*Доступность.\*\* Кнопки с `aria-label`, навигация с клавиатуры.
