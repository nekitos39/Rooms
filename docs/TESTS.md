\# TESTS — Ручные сценарии проверки



\## Каталог аудиторий



\### T-1. Загрузка каталога

1\. Открыть http://localhost:5173

2\. Вкладка «Каталог» → таб «Аудитории»

3\. \*\*Ожидание:\*\* таблица с 4 аудиториями



\### T-2. Поиск аудитории

1\. Ввести «Конференц» в поле поиска

2\. \*\*Ожидание:\*\* остаётся только «Конференц-зал»



\### T-3. Фильтр по вместимости

1\. Ввести «50» в поле «Мин. вместимость»

2\. \*\*Ожидание:\*\* остаются аудитории с capacity >= 50



\## Каталог инвентаря



\### T-4. Загрузка инвентаря

1\. Таб «Инвентарь»

2\. \*\*Ожидание:\*\* 4 ассета



\### T-5. Поиск по инвентарному номеру

1\. Ввести «PRJ» в поиск

2\. \*\*Ожидание:\*\* 2 проектора



\## Брони



\### T-6. Создание брони без конфликта

1\. Вкладка «Управление бронированием»

2\. Заполнить: аудитория «201», название «Тест», время начала 10:00, окончания 11:00

3\. Нажать «Забронировать»

4\. \*\*Ожидание:\*\* зелёный Snackbar «Бронь успешно сохранена»



\### T-7. Создание брони с конфликтом

1\. Создать вторую бронь в той же аудитории с временем 10:30–11:30

2\. \*\*Ожидание:\*\* ошибка «Время занято»



\### T-8. Редактирование брони

1\. Нажать иконку редактирования

2\. Изменить название

3\. Сохранить

4\. \*\*Ожидание:\*\* изменения отобразились в списке



\### T-9. Удаление брони

1\. Нажать иконку удаления

2\. Подтвердить в диалоге

3\. \*\*Ожидание:\*\* бронь исчезла из списка



\## Импорт/Экспорт



\### T-10. Экспорт

1\. Вкладка «Импорт/Экспорт»

2\. Нажать «Скачать JSON»

3\. \*\*Ожидание:\*\* файл `room-assets-export-\*.json` скачан



\### T-11. Импорт валидного файла

1\. Загрузить ранее экспортированный JSON

2\. \*\*Ожидание:\*\* зелёный Alert «Файл валиден. Аудиторий: N, Ассетов: M, Броней: K»



\### T-12. Импорт невалидного файла

1\. Загрузить файл без поля `rooms`

2\. \*\*Ожидание:\*\* красный Alert «Ошибка импорта»



\### T-13. Импорт с конфликтом броней

1\. Загрузить JSON с двумя пересекающимися бронями одной аудитории

2\. \*\*Ожидание:\*\* красный Alert «Конфликт броней»



\## Время



\### T-14. UTC ↔ локальное

1\. Создать бронь на 15:00 локального времени

2\. Открыть DevTools → Network

3\. \*\*Ожидание:\*\* запрос содержит `startTime` в UTC (например, `12:00:00.000Z` для МСК)



\### T-15. Отображение

1\. Создать бронь

2\. \*\*Ожидание:\*\* в списке отображается локальное время (например, «15:00»)
